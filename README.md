# Основной сайт Оренбургского филиала ВНИИПО

Новый WordPress-проект на основе WordPress Conference Service. Первая итерация создаёт структуру основного сайта по документу «2026-10-15 Структура новая (с правками)», отдельную главную страницу и основу для переноса конференционного портала в общий сайт.

Это версия **0.1.0**: структура и программный каркас. Официальные материалы, переводы и рабочая база конференций ещё не перенесены. Точный статус — [docs/status.md](docs/status.md).

## Быстрый запуск

Нужны Git, Docker Desktop с Linux containers и PowerShell 7. Node.js 24 нужен только для проверок и упаковки. Установка npm-зависимостей не требуется.

```powershell
./scripts/dev.ps1
```

Скрипт создаст игнорируемый `.env` со случайными паролями, запустит отдельные контейнеры, установит WordPress, активирует плагины и дочернюю тему, создаст страницы и меню. При повторном запуске редакторское содержимое сохраняется. Используйте скрипт только на новом локальном стенде: он назначает новую главную страницу.

- Сайт: http://localhost:8088/
- WordPress: http://localhost:8088/wp-admin/
- Конференции: http://localhost:8088/conferences/
- Кабинет редактора: http://localhost:8088/editor/conferences/
- Локальный логин и пароль администратора: `WP_ADMIN_USER` и `WP_ADMIN_PASSWORD` в `.env`.

Старый стенд на порту 8080 и его база не используются. Новый сервер слушает только loopback-интерфейс. В конфигурации включён запрет индексации для разработки; это не средство ограничения доступа к production.

## Устройство проекта

```text
wp-content/
  themes/
    vniipo-main/                      новая дочерняя тема основного сайта
    fyremezzonine-wp-theme/           зафиксированная тема конференций
  plugins/
    vniipo-core/                     структура и материалы основного сайта
    fyremezzonine-conference-manager/ существующая логика конференций
docs/                                требования, аудит, планы и инструкции
scripts/                             запуск, проверки и упаковка
compose.yaml                         отдельный локальный стенд
```

Основной сайт использует новую главную и новые общие шаблоны. Карточка и архив конференций наследуются из прежней темы. Владелец типа `conference`, регистрации и таблиц заявок — только Conference Manager.

## Проверки и поставка

```powershell
npm run check
docker compose exec -T wordpress sh -c 'find /var/www/html/wp-content/themes/vniipo-main /var/www/html/wp-content/plugins/vniipo-core /opt/vniipo -name "*.php" -exec php -l {} \;'
docker compose run --rm cli eval-file /opt/vniipo/smoke.php
npm run package
```

Упакованные исходники четырёх компонентов и контрольные суммы появятся в `dist/wordpress`. GitHub Actions выполняет структурные, синтаксические и интеграционные проверки и сохраняет пакет как artifact.

База данных, пароли, uploads и пользовательские заявки в репозитории отсутствуют. Происхождение перенесённых исходников — [docs/upstream-lock.json](docs/upstream-lock.json). Условия использования исходного кода и предоставленных компанией изображений нужно подтвердить до внешнего распространения; новая лицензия за правообладателя не назначается.
