# Статус версии 0.1.0

Дата: 27 октября 2026 года. Это первая рабочая основа проекта, а не завершение всего ТЗ.

## Выполнено

- Создан приватный репозиторий `Doki33935/vniipo-main-site`.
- Изучены прикреплённый Word-документ и предыдущий WordPress Conference Service.
- Сохранены текст ТЗ с номерами абзацев и контрольной суммой, матрица требований и карта страниц.
- Подготовлены архитектура, план разработки, план совершенствования и план интеграции конференций с миграцией и откатом.
- Зафиксированы 29 исходных файлов конференционной темы 1.9.1 и плагина 1.15.1 из Git-коммита `dd3e3a060f0d0d61a29b18be5acc2a39c8ac75b2`.
- Созданы дочерняя тема основного сайта и плагин VNIIPO Core.
- Реализованы реестр 49 страниц, шесть основных пунктов меню, иерархия, канонические ссылки и четыре внутренних 301.
- Реализованы отдельная главная, адаптивное меню с Escape, поиск, страницы, материалы, списки новостей/документов/вопросов и 404.
- Добавлены управляемые через CMS новости, документы, вопросы и анонсы с изображениями.
- Конференционные шаблоны наследуются, существующий плагин остаётся владельцем форм и заявок.
- Добавлены локальное окружение, случайные пароли, повторяемый scaffold, упаковка и GitHub Actions.

## Проверки

Структурная проверка `npm run check` пройдена: 49 страниц, шесть пунктов меню, четыре редиректа, 29 зафиксированных файлов; проверены синтаксис JavaScript и базовая гигиена исходников.

`docker compose config --quiet` пройден. Локальный Docker Desktop не смог поднять Engine: ошибка запуска Inference manager при работе с unix socket `dockerInference`. Сброс Docker или изменение его системных настроек не выполнялись. Полная проверка локального MariaDB/WordPress в этой сессии пока не завершена.

PHP и интеграционные результаты CI будут зафиксированы после выполнения проверок первой публикации исходников. Наличие workflow само по себе не считается пройденным CI.

## Ещё не выполнено

Официальный контент и рабочая БД конференций не перенесены. Не реализованы полный перевод интерфейса/контента, фотослайдер полигона, рабочая подписка, социальные ссылки, точная карта и контактные данные, рекламные интеграции и окончательные презентационные страницы. Не подтверждена production-инфраструктура и не выполнен рабочий деплой.

Страницы с отсутствующими материалами показывают честное пустое состояние. Формы регистрации и кабинет используют существующий Conference Manager, но реальные заявки и пользователи старого портала остаются в прежнем контуре.

Следующий этап — согласование структуры и материалов, затем наполнение и репетиция миграции конференций на staging. Подробности: `roadmap.md`, `conference-integration.md`, `decisions.md`.
