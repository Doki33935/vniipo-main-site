# Статус версии 0.2.0

Дата: 27 октября 2026 года. Реализованы основа нового сайта и безопасный способ показать его администраторам существующего конференционного WordPress.

## Новое в 0.2.0

- Исследованы фактические HTML и CSS vniipo.ru, полученные напрямую с HTTP 200. Оформление адаптировано под Оренбургский филиал: тёмно-синяя шапка, центральное название, эмблемы, светлое меню, компактный информационный макет и боковая колонка.
- Сохранены все 49 разделов структуры, поиск, новости, документы, вопросы, анонсы и интеграция конференционных шаблонов.
- Добавлен VNIIPO Private Preview: закрытый адрес `/vniipo-preview/` для пользователей с `manage_options`.
- Предпросмотр работает с неактивной новой темой и неактивным VNIIPO Core. Включать core и создавать страницы на рабочем портале ради показа не требуется.
- Подготовлен `scripts/build-preview.ps1`: три ZIP для загрузки через WordPress, инструкция и SHA-256. Родительская тема, Conference Manager, WordPress core и рабочие данные в пакет просмотра не входят.
- Инструкция установки, ограничения и отключение: `hosting-preview.md`. Происхождение оформления: `design-reference.md`.

## Проверки

Проверки выполнялись на отдельном локальном стенде: WordPress 7.0.2, PHP 8.3.36, MariaDB 11.4.10, WP-CLI 2.12.0. Рабочий хостинг не изменялся.

- `npm run check`: 49 страниц, шесть пунктов меню, четыре внутренних 301, целостность 29 зафиксированных файлов старого проекта и синтаксис JavaScript.
- PHP: синтаксис 27 файлов без ошибок. PowerShell: проверен синтаксис скриптов запуска и сборки.
- Основной сайт: 62 HTTP-проверки, включая разделы, поиск, 404, редиректы, конференции, регистрацию, вход, документы, вопросы и пагинацию новостей.
- Предпросмотр: 65 HTTP-проверок со старой конференционной темой в качестве активной и отключённым VNIIPO Core. Проверены все разделы, конференции, доступ администратора, отказ редактору/гостю, запрет POST/PUT/DELETE, HEAD, поиск и его вторая страница, пагинация новостей и сохранение публичного оформления. Всего два набора содержат 127 HTTP-проверок.
- Сверка БД: сохранены `stylesheet`, `template`, `show_on_front`, `page_on_front`, количество записей, метаданных и заявок; VNIIPO Core остался неактивным во время показа.
- После исправления предупреждений для виртуальных страниц debug.log пуст.
- В браузере проверены ширины 1440 и 390 px, работа меню и Escape, отсутствие горизонтального скролла.

Первый GitHub Actions запуск версии 0.1.0 был заблокирован ограничением оплаты/spending limit аккаунта до выполнения шагов. В 0.2.0 workflow дополнен проверками предпросмотра; успешное выполнение CI не заявляется. Локальный Docker ранее завершался с ошибкой Inference manager; проверки приложения выполнены на изолированных portable PHP/MariaDB. Системные настройки Docker и оплата аккаунта не менялись.

## Границы готовности

Пакет подготовлен для установки ответственным администратором. На удалённый хостинг он ещё не устанавливался: нужно подтвердить адрес WordPress, право установки компонентов и веб-версию PHP 8.3. Публичная главная конференционного сайта не переключалась.

Официальное наполнение, полноценные переводы, фотослайдер полигона, подписка, социальные ссылки, точная карта и контакты, а также перенос рабочих конференций и заявок остаются следующими этапами. Предпросмотр не заменяет отдельный staging для редактирования, тестирования форм и миграции.

Текст исходного ТЗ и карта соответствия сохранены. Конференционная тема 1.9.1 и плагин 1.15.1 по-прежнему зафиксированы коммитом `dd3e3a060f0d0d61a29b18be5acc2a39c8ac75b2`; их исходники в этой итерации не менялись.
