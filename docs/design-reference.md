# Основа оформления vniipo.ru

27 октября 2026 года по запросу пользователя изучены HTML главной https://vniipo.ru/ и подключённые стили, включая https://vniipo.ru/arrcss/style.css. Основная страница получена напрямую с HTTP 200. Встроенный браузер и веб-извлечение в этой сессии не смогли открыть живую страницу, поэтому исследование основано на фактически скачанных HTML/CSS и изображениях, а не на предположении о её внешнем виде.

## Что взято за основу

| Элемент | На официальном сайте | В новой теме |
| --- | --- | --- |
| Основной цвет | Шапка и подвал `#274472` | Та же базовая палитра |
| Навигация | Светлый фон `#f2f4f9`, голубой акцент `#63b2f5` | Светлое меню с активным/hover-состоянием |
| Ссылки | Синий `#4174c5` | Ссылки и основные кнопки |
| Подложки | Голубовато-серый `#e2eaf2` | Быстрые ссылки и заголовки боковых блоков |
| Шапка | Эмблема ВНИИПО слева, название в центре, эмблема МЧС справа | Та же композиция с названием Оренбургского филиала |
| Информационная плотность | Баннеры, новости, боковая колонка | Главный анонс, быстрые переходы, новости, направления и сервисы справа |
| Текст | Open Sans, Segoe UI, Arial, размер около 15px | Та же последовательность локальных шрифтов без внешнего запроса Google Fonts |

CSS темы написан заново. Скрипты, рекламные блоки, аналитика, формы, новости и федеральный контент официального сайта не импортировались. Большой первый экран первой версии заменён более компактной информационной компоновкой. Пустые редакторские разделы остаются явно обозначенными.

## Изображения

В `assets/` новой темы сохранены эмблемы из шапки официального сайта:

- `institute-emblem.png`: https://vniipo.ru/arrimg/3Iuey8eUnxc.png;
- `mchs-emblem.png`: https://vniipo.ru/arrimg/vyhsds.png.

Это фирменные материалы организации, использованные по поручению пользователя для проекта филиала. Новая лицензия на них не назначается. Перед окончательным рабочим выпуском заказчик подтверждает утверждённые версии эмблем и точное полное наименование филиала. Логотип ВНИИПО можно заменить через стандартную настройку логотипа темы.

Макет адаптируется к мобильной ширине; главное меню остаётся доступно через кнопку и клавиатуру. Источник задаёт направление оформления, а не требование копировать его устаревшие технические приёмы, внешние зависимости или фиксированные ограничения мобильной версии.
