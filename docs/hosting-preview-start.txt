КОМПЛЕКТ ПРОСМОТРА НОВОГО САЙТА ВНИИПО

1. Распакуйте общий архив на компьютере.
2. Откройте START-HERE.html обычным браузером. Это пошаговая инструкция.
3. Загружайте три внутренних ZIP в WordPress по отдельности:
   vniipo-main.zip    -> Темы; установить, ОСТАВИТЬ НЕАКТИВНОЙ.
   vniipo-core.zip    -> Плагины; установить, ОСТАВИТЬ НЕАКТИВНЫМ.
   vniipo-preview.zip -> Плагины; установить и АКТИВИРОВАТЬ.
4. Откройте Инструменты -> Предпросмотр ВНИИПО -> Открыть новый сайт.

Старая конференционная тема остаётся активной. Старые тема и Conference
Manager в комплект не входят и не заменяются. Главная, конференции,
регистрация и кабинеты продолжают работать на обычных адресах.

Требования: WordPress 6.9+, PHP 8.3+, административная учётная запись.
Доступ к новому сайту: /vniipo-preview/ внутри существующего WordPress.
Для отключения деактивируйте VNIIPO Private Preview.

Сам общий архив не загружают в WordPress как плагин.
Полная инструкция: INSTALL.md. Контрольные суммы: SHA256SUMS.txt.
Комплект не запускает миграцию базы и не публикует новый сайт.
