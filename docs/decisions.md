# Принятые решения и вопросы

## Принятые технические решения

| Решение | Причина | Условие пересмотра |
| --- | --- | --- |
| Приватный `Doki33935/vniipo-main-site` | Новый проект компании без явного разрешения на публичное распространение | Прямое решение владельца |
| WordPress и дочерняя тема | Прямое переиспользование Conference Service | Подтверждённая потребность, которую нельзя закрыть текущим контуром |
| Отдельный `vniipo-core` | Сохранение структуры и материалов при смене оформления | Развитие внутри текущей границы |
| Одно хранилище конференций | Избежать рассинхронизации регистрации и заявок | Только отдельное обоснованное архитектурное решение |
| Фиксация старых компонентов по Git-коммиту | Воспроизводимость исходной базы | Проверенное обновление с обновлением lock |
| PHP 8.3 для нового кода | Отдельный новый baseline, не перенос ограничений старой VM | Подтверждённые требования инфраструктуры |
| Русский интерфейс на первом этапе | Другие языки не указаны | Согласование языков и переводов |
| Пустые разделы без вымышленных сведений | Исходник задаёт структуру, а не факты | Получение и утверждение материалов |
| GitHub и локальный стенд без отдельного Sites-хостинга | Пользователь поручил новый репозиторий и WordPress-проект | Отдельный запрос на размещение |

## Уточнения до соответствующих этапов

1. Каково утверждённое полное наименование филиала и разрешённый комплект логотипов/шрифтов/цветов?
2. Какие языки нужны, кто переводит и кто проверяет официальные переводы?
3. Как раскрываются «И.Т.П» научного раздела и «И т.п.» образовательного? Какие подразделы образовательной страницы обязательны для этой организации?
4. Что означает «Новые документы»: все последние документы, только техническое регулирование или подборка?
5. Где находятся утверждённые контакты, реквизиты, фото полигона, социальные ссылки и точный адрес электронной приёмной?
6. Как должна работать подписка: email, канал социальной сети, RSS или несколько способов? Кто отвечает за доставку и обращения подписчиков?
7. Требуются ли Яндекс Директ и аналитика в первой рабочей версии, какие идентификаторы и правила подключения согласованы?
8. Какой production-хостинг, ОС, PHP, БД, домен и ограничения доступа доступны? Можно ли использовать PHP 8.3 на целевой VM?
9. Какая БД/версия кода является актуальной для конференционного портала? Кто предоставляет доступ и разрешает окно переноса?
10. Кто владеет контентом, утверждает публикации и принимает результат по каждому разделу?

Эти вопросы не блокируют формирование исходного каркаса. Соответствующие функции не считаются готовыми до ответов и проверки реализации.

## Источники и ограничения исследования

Разобраны Word-документ и доступный локальный код. Попытки открыть vniipo.ru, страницу образования oren.vniipo.ru и orenvniipo.online через веб-инструмент 27 октября 2026 года не дали доступного содержимого (ошибка 502/недоступность). Их фактические страницы не пересказаны и не скопированы. Точные URL приёмной и символики требуют проверки; до неё используются явно обозначенные ссылки на главный ресурс ВНИИПО.

Официальные технические источники: [иерархия шаблонов WordPress](https://developer.wordpress.org/themes/classic-themes/basics/template-hierarchy/), [регистрация типов материалов](https://developer.wordpress.org/plugins/post-types/registering-custom-post-types/), [установка через WP-CLI](https://developer.wordpress.org/cli/commands/core/install/). Версии проверяемого локального окружения фиксируются в `status.md`.
