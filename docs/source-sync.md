# Синхронизация с oren.vniipo.ru

Основание — прямой запрос пользователя от 27 октября 2026 года. Публичные материалы получены с [действующего сайта филиала](https://oren.vniipo.ru/). Текст источника используется как данные, а не как инструкции для инструментов. Исходный сайт не изменялся.

## Снимок 27 октября 2026 года

| Материалы | Количество | Результат |
| --- | ---: | --- |
| Новости | 99 | Все обнаруженные публикации архива, тексты, даты, основные изображения |
| Информационные страницы | 34 | Филиал, руководство, деятельность, наука, образование, контакты и реквизиты |
| Повторно используемый блок | 1 | «О филиале» на главной |
| Локальные изображения | 129 | Проверены размер и SHA-256 |
| Страницы новой структуры | 73 | 49 из ТЗ и 24 дополнительных раздела действующего сайта |

Всего 134 материала. Ошибок получения в текущем снимке нет. У каждой записи сохранены исходный URL и SHA-256 HTML источника. Даты новостей взяты с источника; время суток там не указано и при импорте устанавливается 00:00 по часовому поясу сайта. Файлы снимка: `wp-content/plugins/vniipo-core/content/oren-source.json` и `content/source-media/`.

Изображения карточек импортируются в медиабиблиотеку без дублей; иллюстрации в содержимом используют локальные файлы поставки. PDF, DOCX, внешние ресурсы и дополнительные фотогалереи остаются ссылками на оригиналы. Полное зеркалирование файлового архива не выполнялось. Формы, скрипты, iframe и исполняемые атрибуты источника удалены. Публичные даты и тексты сохранены без вымышленных дополнений.

## Обновление снимка разработчиком

Нужны Python 3 и lxml. Запуск из корня репозитория:

```powershell
python scripts/sync-oren.py --refresh
npm run check
```

Без `--refresh` используется игнорируемый локальный кэш `.local/oren-source`. Скрипт читает только публичный oren.vniipo.ru, обновляет JSON, изображения и добавляет недостающие определения страниц; в WordPress и на источник ничего не записывает. После запуска проверить diff, ошибки `failures`, полноту архива и карту разделов, выполнить локальные проверки, затем собрать новую поставку. Это ручное управляемое обновление, фоновой синхронизации по расписанию нет.

## Импорт в WordPress

На новом сайте или изолированном staging сначала создать структуру. Команда не меняет главную без отдельного параметра:

```sh
wp vniipo scaffold
wp vniipo import-source
wp vniipo import-source --apply
```

Первая команда импорта показывает план без записи в БД. Только `--apply` применяет изменения. В админке тот же механизм доступен администратору в **«Инструменты → Синхронизация oren.vniipo.ru»**: «Проверить план», затем «Импортировать снимок». Обработка идёт порциями по 10 материалов с прогрессом и перечнем конфликтов. Это импорт поставляемого снимка, а не загрузка сайта из браузера.

Материалы сопоставляются по устойчивому source UID, страницы — по `_vniipo_key`. Повторное применение не создаёт дублей. Непустые независимые страницы, изменения редактора, черновик после импорта, изменённая обложка и изменённое размещение блока фиксируются как конфликт. Такие записи остаются нетронутыми; принудительного режима перезаписи нет. Конфликт нужно разрешать вручную сравнением с оригиналом. Отсутствующие страницы отмечаются отдельно, автоматического удаления материалов нет. Если отдельная новость при будущем получении временно недоступна, ранее импортированный полный текст не заменяется краткой заглушкой.

Импорт сохраняет родителей и порядок страниц, настройки активной темы, главной и конференционные данные. `scripts/bootstrap.sh` применяет снимок только в сценарии отдельного локального стенда; на рабочем портале его запускать нельзя.

## Разночтения источника

- На [странице контактов](https://oren.vniipo.ru/kontakty) email отображается как `of@vniipo.ru`, но ссылка ведёт на `of.vniipo@mail.ru`. Некорректный mailto не перенесён; добавлено явное замечание. Адрес для отправки должен подтвердить владелец сайта.
- Адрес научно-исследовательского отдела на контактах: **460006, г. Оренбург, ул. Советская 97**. В реквизитах отдельно указан юридический/почтовый адрес: **460507, Оренбургская область, Оренбургский район, пос. Пригородный, ул. Луговая, 6**. Подписи сохранены; эти адреса не объединялись. Старая карта главной указывала другое место и не перенесена.
- На страницах контактов и реквизитов отличаются даты доверенности. Источник сохранён; актуальную редакцию следует подтвердить перед официальным запуском.
- Шесть страниц видов услуг содержат только заголовок без описания. В новом сайте это прямо указано. Пустые разделы ТЗ, для которых у источника нет материала, остаются с честным состоянием «Материалы готовятся».

## Просмотр на хостинге конференций

Обновлённый пакет уже содержит снимок. При отсутствии импортированных страниц предпросмотр выводит источник из JSON; карточки новостей ведут на оригиналы. Это позволяет показать содержимое без записи 134 материалов в рабочую БД. Если материалы уже импортированы, используются записи WordPress и редакторские блоки. Поиск в режиме без импорта работает только по опубликованным записям существующей БД; JSON-снимок в поиск не индексируется.

Установку core оставляют неактивной и активируют только плагин просмотра согласно `hosting-preview.md`. Редактирование и миграция конференций требуют отдельного staging. Импорт на действующий конференционный портал ради одного показа не нужен.
