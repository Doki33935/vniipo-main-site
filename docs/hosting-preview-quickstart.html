Установка нового сайта ВНИИПО в закрытый просмотр

Комплект для администратора действующего WordPress с конференциями. После установки обычные адреса продолжает обслуживать прежняя активная тема. Новый сайт доступен только администраторам по отдельному адресу.

Сначала распакуйте общий комплект на компьютере. В админку WordPress загружаются три внутренних ZIP по отдельности. Сам общий архив не является плагином.

1 Подготовка

  • Убедитесь, что есть резервная копия текущих файлов и базы. Запишите название активной темы.
  • В WordPress откройте «Инструменты → Здоровье сайта → Информация → Сервер». Нужны PHP 8.3 или новее и WordPress 6.9 или новее. Если версии ниже, отложите установку и передайте сведения разработчику; изменение версии PHP рабочего сервиса требует отдельной проверки.
  • Должны быть установлены прежняя тема с каталогом fyremezzonine-wp-theme и действующий Conference Manager. Их сохраняют в текущем состоянии.
  • Core ZIP занимает около 14 МБ. Если WordPress отклоняет размер, используйте файловый менеджер хостинга или SFTP по полной инструкции INSTALL.md.
  • Для внешнего page cache/CDN исключите адрес /vniipo-preview/ и все его вложенные страницы.

2 Три файла и их состояние

АрхивКуда загрузитьПосле установки
vniipo-main.zipВнешний вид → Темы → Добавить → ЗагрузитьОставить неактивной. Прежняя тема остаётся активной.
vniipo-core.zipПлагины → Добавить → ЗагрузитьОставить неактивным. Файлы будут подгружаться только внутри разрешённого просмотра. Если core уже используется на этом сайте, его текущее состояние согласуйте с ответственным.
vniipo-preview.zipПлагины → Добавить → ЗагрузитьАктивировать только этот новый плагин.

Если WordPress сообщает, что компонент уже установлен, сначала сверяйте его версию и назначение. Автоматически заменять неизвестные действующие компоненты не следует.

3 Открытие нового сайта

  1. Войдите своей административной учётной записью в существующий WordPress.
  2. Откройте «Инструменты → Предпросмотр ВНИИПО → Открыть новый сайт».
  3. Адрес: адрес-вашего-WordPress/vniipo-preview/. Например, при установке в корне https://orenvniipo.online/ это https://orenvniipo.online/vniipo-preview/. Фактическую ссылку берите из страницы инструмента.
  4. Передайте эту ссылку другим администраторам. Каждый входит под своей учётной записью. Роль «Редактор» без права управления настройками доступа к просмотру не имеет.

4 Что проверить после установки

  • Обычная главная в приватном окне браузера выглядит как прежний конференционный сайт.
  • Прежние адреса конференций, регистрации и кабинетов открываются в прежнем оформлении.
  • В административной сессии на /vniipo-preview/ видны новая шапка, страницы и полоса «Закрытый предпросмотр».
  • Гость попадает на вход WordPress, пользователь без административных прав получает отказ.
  • Активная тема и назначенная главная сохранились; импорт материалов и изменение структуры базы не запускались.

5 Границы просмотра

Новые разделы и материалы показываются из поставляемого снимка, существующие конференции — из действующей базы. При отсутствии импортированных новостей карточки ведут на публикации источника. Поиск работает по опубликованным записям действующей базы.

Это просмотр для согласования оформления. Отправка форм и работа кабинетов внутри просмотра отключены; в обычном конференционном сервисе они остаются на прежних адресах. Для редактирования нового сайта и проверки форм используется отдельный staging.

Ради показа не запускают bootstrap, scaffold, импорт снимка или дампа; не активируют новую тему, Polylang и VNIIPO Core. Переводы и рабочая миграция конференций подключаются отдельным этапом.

6 Как отключить просмотр

В «Плагины» деактивируйте VNIIPO Private Preview. Публичная тема сохраняется. Неактивные новая тема и core могут остаться установленными. Если обычные страницы неожиданно изменились, проверьте, что не была вручную активирована VNIIPO Main; верните записанную перед установкой прежнюю тему.

Полная инструкция: INSTALL.md. Проверка комплекта: SHA256SUMS.txt и MANIFEST.json. В комплект включены только новая тема, новый core и просмотр; работающие компоненты конференций, база и пароли сюда не входят.
