# Добавление информационных блоков

В версии 0.3.0 добавлено меню WordPress **«Информационные блоки»**. Оно предназначено для самостоятельного наполнения сайта редакторами: текст, изображения, списки, таблицы и ссылки на загруженные файлы создаются в штатном блочном редакторе. Новости продолжают публиковаться в «Записях», анонсы, документы и вопросы — в своих разделах. Конференции обслуживает прежний Conference Manager.

## Как разместить новый блок

1. Открыть «Информационные блоки → Добавить информационный блок».
2. Указать название и заполнить содержимое. Кнопка «+» позволяет добавить абзац, изображение, галерею, таблицу или файл из медиабиблиотеки.
3. В панели «Размещение блока» выбрать область: перед новостями, после новостей, внизу главной, в боковой колонке главной или после содержимого страницы раздела.
4. Для области страниц при необходимости выбрать конкретную страницу. Пустое значение означает все страницы разделов.
5. В этой же панели задать «Порядок»: меньшее число выводится раньше. При равных значениях сохраняется порядок создания.
6. Нажать «Опубликовать» и проверить страницу. Черновики, приватные и удалённые блоки не выводятся. Для временного скрытия достаточно вернуть блок в черновик.

Количество блоков не зафиксировано в шаблоне. Области страницы доступны как на основном сайте, так и в закрытом предпросмотре. Размещение на страницах распространяется на информационные разделы из реестра, а не на конференционные кабинеты и карточки новостей.

## Повторное использование

Для вставки в произвольную страницу выбрать область «Только вставка в редакторе или shortcode». В редакторе страницы добавить блок **«Информационные блоки ВНИИПО»** и указать ID материала из панели размещения. Содержимое редактируется один раз в меню «Информационные блоки»; вставки показывают актуальную опубликованную версию.

Для классического редактора доступны:

```text
[vniipo_block id="123"]
[vniipo_blocks area="manual"]
```

Первый вариант выводит один опубликованный блок, второй — все блоки выбранной области в установленном порядке. Вложенные вставки информационных блоков внутри самих блоков намеренно не разворачиваются рекурсивно.

На главной уже создан блок «О филиале» с подтверждённым текстом oren.vniipo.ru. Его можно редактировать как обычный материал. Повторная синхронизация зафиксирует редакторское изменение как конфликт и сохранит его.

## Где редактировать

На новом сайте или отдельном staging должны быть активны VNIIPO Core и VNIIPO Main. Закрытый просмотр на действующем конференционном хостинге предназначен для показа: там core может оставаться неактивным, а материалы читаются из поставляемого снимка без импорта. Ради добавления тестовых блоков не следует активировать core или импортировать новости в рабочую конференционную БД; полноценное редактирование сначала проверяется на staging.
